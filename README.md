# Scoop & Swirl

Interactive website for an oceanfront ice cream shop: a shipping-container shop on the beach at sunset.

- Tap the serving window for the **Menu**, the rooftop sign for **Our Story**, the signpost for **Find Us & Contact**, the Members board for **Customer Login**, and the STAFF ONLY sign for the **Admin** login.
- "Paint the shop" changes the container colour.
- Plain HTML, CSS and JavaScript. No build step.

Backend: Firebase (Auth + Firestore). See [FIREBASE_SETUP.md](FIREBASE_SETUP.md). Until it's configured, logins and messages run in demo mode in each visitor's browser.
